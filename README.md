# Archimedes – World Physics Olympiads Bank

Public site of Archimedes – World Physics Olympiads Bank (eisatopon.gr): physics olympiad problems — IPhO theoretical problems first — in English with LaTeX, statements only.

Live: https://eisatopon.github.io/physics-olympiads-bank/

This repository holds only the files the site loads. The problems remain the work of their authors and organising committees.
Sister project: [Pythagoras – World Mathematical Olympiads Bank](https://eisatopon.github.io/national-olympiads-bank/).
